Piece icon library

106 files. White pieces sit on a dark square and black pieces on a light one, so the outlines read either way. The shogi tiles are single-colour and shown once — that set distinguishes the two players by rotating a piece 180°, not by recolouring it. Xiangqi does recolour, and also uses a different character per side, so it has real pairs; its -white is the red side. Licensing per file is in CREDITS.md.
